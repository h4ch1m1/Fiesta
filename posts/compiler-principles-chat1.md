# 编译原理笔记 1：文法与语言基础

这篇笔记整理编译原理开头最常用的一组概念：编译程序的工作阶段、符号串的基本运算、文法的四元组定义、推导与归约，以及乔姆斯基层次中的四类文法。

## 1. 编译程序做什么

编译程序是一种翻译程序。它把源语言程序翻译成语义等价的目标语言程序，目标语言通常是汇编代码、机器代码或某种中间形式。

典型编译流程：

- 词法分析：扫描源程序的字符流，识别单词符号，也就是 token。
- 语法分析：根据文法规则判断 token 序列是否符合语法结构，并构造语法树或分析树。
- 语义分析：检查程序语义是否正确，例如变量是否声明、类型是否匹配、作用域是否合法。
- 中间代码生成：把源程序转换成便于优化和生成目标代码的中间表示。
- 代码优化：在不改变程序语义的前提下，提高执行效率或减少资源消耗。
- 目标代码生成：把中间代码翻译成目标机器代码或汇编代码。

## 2. 字母表、符号串与子串

字母表是一个有限的非空符号集合，通常记为 `Σ`。例如：

`Σ = {a, b, c}`

在这个字母表上，`a`、`ab`、`ac` 都是符号串。

空串是不含任何符号的符号串，记为 `ε`。符号串长度常用绝对值符号表示：

- `|ab| = 2`
- `|ε| = 0`

对于 `X = abc`，`ε`、`a`、`b`、`c`、`ab`、`bc`、`abc` 都是它的子串；`ba` 不是 `abc` 的子串。空串 `ε` 是任意符号串的子串。

## 3. 头、尾与固有头尾

对于 `z = abc`：

- `ε`、`a`、`ab`、`abc` 都是 `z` 的头，也叫前缀。
- 除 `abc` 本身之外，其余前缀叫固有头，也叫真前缀。
- `ε`、`c`、`bc`、`abc` 都是 `z` 的尾，也叫后缀。
- 除 `abc` 本身之外，其余后缀叫固有尾，也叫真后缀。

## 4. 符号串的连接与幂

符号串可以连接。若 `x = ab`，`y = cd`，则：

`xy = abcd`

符号串的幂表示重复连接：

- `x^0 = ε`
- `x^1 = x`
- `x^2 = xx`
- `x^3 = xxx`

一般地，`x^n` 表示 `n` 个 `x` 连接在一起。

## 5. 符号串集合与语言

如果集合 `A` 中的所有元素都是字母表 `Σ` 上的符号串，则称 `A` 为 `Σ` 上的符号串集合，也可以说 `A` 是 `Σ` 上的一个语言。

例如：

- `Σ = {1, 2, 3}`
- `A = {12, 13, 23, 231, ...}`

则 `A` 是 `Σ` 上的符号串集合。

两个符号串集合 `A`、`B` 的乘积定义为：

`AB = {xy | x ∈ A, y ∈ B}`

例如：

- `A = {1, 2}`
- `B = {5, 6, 7}`
- `AB = {15, 16, 17, 25, 26, 27}`

## 6. 闭包与正闭包

字母表 `Σ` 的闭包 `Σ*` 是 `Σ` 上所有长度为 `n` 的符号串组成的集合，其中 `n >= 0`。

字母表 `Σ` 的正闭包 `Σ+` 是 `Σ` 上所有长度为 `n` 的符号串组成的集合，其中 `n > 0`。

例如 `Σ = {a, b, c}`：

- `Σ* = {ε, a, b, c, aa, ab, ac, ba, bb, bc, ca, cb, cc, ...}`
- `Σ+ = {a, b, c, aa, ab, ac, ba, bb, bc, ca, cb, cc, ...}`

区别很简单：`Σ*` 包含空串 `ε`，`Σ+` 不包含空串 `ε`。

## 7. 文法与语言

一个文法通常表示为：

`G = (V_N, V_T, P, S)`

其中：

- `V_N` 是非终结符集合。
- `V_T` 是终结符集合。
- `P` 是产生式集合，也叫重写规则集合。
- `S` 是开始符号，也叫识别符号。`S` 是一个非终结符，不是一个集合。

非终结符是可以继续被替换、展开的符号；终结符是不能继续被替换、展开的符号。

常见书写约定：

- 用尖括号括起来的符号通常表示非终结符。
- 不用尖括号的符号通常表示终结符。
- 有些教材用大写字母表示非终结符，用小写字母表示终结符。
- 这些只是书写约定，关键是前后一致。

## 8. 产生式

产生式用来描述符号之间的替换关系。

- `->` 或 `::=` 表示“定义为”。
- `|` 表示“或者”。
- 定义号左侧称为产生式左部。
- 定义号右侧称为产生式右部。

例如，标识符文法可以写作：

`G[<标识符>]`

- `<标识符> -> <字母>`
- `<标识符> -> <标识符><数字>`
- `<标识符> -> <标识符><字母>`
- `<字母> -> a | b | c | ... | z`
- `<数字> -> 0 | 1 | 2 | ... | 9`

在这个文法中：

- `V_N = {<标识符>, <字母>, <数字>}`
- `V_T = {a, b, c, ..., z, 0, 1, 2, ..., 9}`
- `P` 是所有产生式组成的集合。
- `S = <标识符>`

这个文法能生成 `a`、`ab`、`a1`、`abc123`，不能生成 `1a`、`9abc`，因为它规定标识符必须以字母开头。

## 9. 推导、归约、句型与句子

设：

- `v = 233<字母>666`
- `w = 233a666`

如果有产生式：

`<字母> -> a`

则称 `v` 直接推导出 `w`，记为：

`v => w`

反过来也可以说，`w` 直接归约为 `v`。

推导长度：

- 若 `V => W`，则推导长度为 `1`。
- 若 `V = W`，则推导长度为 `0`。
- 若 `V` 经过一步或多步推导得到 `W`，记为 `V =>+ W`。
- 若 `V` 经过零步或多步推导得到 `W`，记为 `V =>* W`。

其中，`=>+` 表示正闭包意义上的推导，要求推导步数 `n >= 1`；`=>*` 表示闭包意义上的推导，允许推导步数 `n >= 0`。

设文法 `G` 的开始符号为 `Z`，并且 `V = V_N ∪ V_T`。

- 如果 `Z =>* X`，且 `X ∈ V*`，则称 `X` 为文法 `G` 的一个句型。
- 如果 `Z =>* X`，且 `X ∈ V_T*`，则称 `X` 为文法 `G` 的一个句子。
- 句子是一种特殊的句型。

文法 `G` 描述的语言是该文法所有句子的集合，记为：

`L(G) = {x | Z =>* x, 且 x ∈ V_T*}`

## 10. 文法分类：乔姆斯基层次

乔姆斯基层次把文法分为 0 型、1 型、2 型、3 型。它们的限制越来越强，能描述的语言范围越来越小：

`0 型文法 ⊇ 1 型文法 ⊇ 2 型文法 ⊇ 3 型文法`

也可以说：

`短语结构文法 ⊇ 上下文有关文法 ⊇ 上下文无关文法 ⊇ 正规文法`

## 11. 0 型文法：短语结构文法

0 型文法也叫短语结构文法。产生式一般形式为：

`α -> β`

要求：

- `α` 至少含有一个非终结符。
- `β` 可以是由终结符和非终结符组成的任意符号串。

0 型文法限制最少，描述能力最强，对应图灵机可识别的语言。编译原理入门阶段通常了解即可。

## 12. 1 型文法：上下文有关文法

1 型文法也叫上下文有关文法。常见产生式形式为：

`αAβ -> αγβ`

其中：

- `A` 是非终结符。
- `α`、`β` 是上下文。
- `γ` 是非空符号串。

含义是：`A` 能否被替换成 `γ`，要看它左右两边的上下文 `α` 和 `β`，因此称为上下文有关。

1 型文法通常要求产生式右部长度不小于左部长度，即：

`|右部| >= |左部|`

特殊情况：如果语言允许空串，可以允许 `S -> ε`，但 `S` 不能出现在任何产生式右部。

上下文有关文法可以描述一些上下文无关文法不能描述的语言，例如：

`L = {a^n b^n c^n | n >= 1}`

也就是 `abc`、`aabbcc`、`aaabbbccc` 等。这类语言要求 `a`、`b`、`c` 的个数相同，约束更强。

## 13. 2 型文法：上下文无关文法

2 型文法也叫上下文无关文法，简称 CFG。产生式一般形式为：

`A -> β`

其中：

- `A` 是单个非终结符。
- `β` 是由终结符和非终结符组成的符号串。

含义是：`A` 可以在任意上下文中被替换成 `β`，不需要看 `A` 左右两边是什么符号，因此称为上下文无关。

例如：

- `S -> aSb`
- `S -> ε`

这个文法可以生成 `ε`、`ab`、`aabb`、`aaabbb`。它描述的语言是：

`L = {a^n b^n | n >= 0}`

上下文无关文法在编译原理中非常重要，常用于描述程序设计语言的语法结构，例如表达式、语句、声明等：

- `<声明语句> -> <类型> id ;`
- `<类型> -> int | float`

这里 `<声明语句>` 和 `<类型>` 都可以在不考虑左右上下文的情况下展开。

## 14. 3 型文法：正规文法

3 型文法也叫正规文法。正规文法分为右线性文法和左线性文法。

右线性文法产生式形式：

- `A -> aB`
- `A -> a`
- `A -> ε`

左线性文法产生式形式：

- `A -> Ba`
- `A -> a`
- `A -> ε`

其中 `A`、`B` 是非终结符，`a` 是终结符。

正规文法可以描述正规语言，对应有限自动机和正则表达式。编译器中的词法分析通常使用正规文法、正则表达式或有限自动机来描述和识别单词符号。

例如：

- `S -> aS`
- `S -> bS`
- `S -> a`
- `S -> b`

这个文法可以生成所有由 `a`、`b` 组成且长度至少为 1 的符号串：

`L = {a, b}+`

## 15. 四类文法对比

- 0 型文法：短语结构文法；产生式限制最少；能力最强。
- 1 型文法：上下文有关文法；通常满足 `|右部| >= |左部|`；替换非终结符时可能需要依赖上下文。
- 2 型文法：上下文无关文法；产生式左部必须是单个非终结符；程序设计语言的语法分析常用它。
- 3 型文法：正规文法；产生式最受限制；词法分析常用它；与正则表达式、有限自动机关系密切。

判断一个文法属于哪一型，通常看产生式左部和右部的形式：

- 如果左部可以是任意含非终结符的符号串，一般至少是 0 型文法。
- 如果每条产生式都满足 `|右部| >= |左部|`，通常可以考虑 1 型文法。
- 如果每条产生式左部都是单个非终结符，则是上下文无关文法，也就是 2 型文法。
- 如果每条产生式都形如 `A -> aB`、`A -> a`，或都形如 `A -> Ba`、`A -> a`，则是正规文法，也就是 3 型文法。

需要注意：同一个文法如果满足更严格类型的条件，通常也满足更宽松类型的条件。例如，正规文法一定是上下文无关文法。
